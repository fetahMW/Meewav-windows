## Contrôle des références et de l'intégrité

Avant chaque déplacement : chemin absolu résolu et borné dans ce dépôt ; absence de jonction/lien dans le chemin ; destination inexistante ; empreinte source identique à l'inventaire ; document dans la liste autorisée ; aucune référence entrante ni lien relatif sortant repéré. La recherche statique couvre les fichiers texte suivis et les fichiers locaux non ignorés pertinents, plus le README ignoré. Elle ne peut attester des liens construits dynamiquement ni des références hors dépôt. Aucun test, build ou navigateur n'est lancé.

Les sources remplacées sont copiées avant tout déplacement. À l'issue des opérations, toutes les empreintes d'archives et des originaux conservés sont comparées, les fichiers personnels préexistants sont contrôlés, et les changements Git sont bornés à la liste autorisée.
