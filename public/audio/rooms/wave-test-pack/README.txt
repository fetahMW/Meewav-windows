LA WAVE — TEST PACK
=====================

Pack audio original et synthétique, conçu spécifiquement pour tester le workflow La Wave.

CONTENU
-------
Genres:
- Afro — 100 BPM — A minor
- Drill — 142 BPM — F minor
- Trap — 150 BPM — C minor
- Zouk — 92 BPM — G minor
- House — 124 BPM — A minor

Dans chaque genre:
- Drums A / Drums B
- Bass A / Bass B
- Melody A / Melody B
- Acapella_Test A (vocal chop synthétique, aucune voix/sampling externe)
- FullMix A
- Kit one-shots: Kick, Snare, Clap, Hat, Perc

USAGE CONSEILLÉ DANS LA WAVE
----------------------------
- Variante A = première proposition d’un participant
- Variante B = challenger pour vote / duel / remplacement
- FullMix = test lecteur global / preview
- Acapella_Test = test catégorie Acapella
- Length_Validation = test précis des formats 4 / 8 / 16 mesures

SPÉCIFICATIONS
--------------
- WAV PCM 16-bit stereo
- 44.1 kHz
- Boucles calées exactement sur la grille
- Aucun sample commercial ni contenu protégé
- Niveaux normalisés pour éviter les clips pendant les tests

TESTS À FAIRE
-------------
1. Import d’une boucle par participant
2. Classement Drums / Bass / Melody / Acapella
3. Écoute solo
4. Écoute avec le beat collectif
5. Vote A vs B
6. Égalité de vote
7. Duel de remplacement
8. Mute / Solo
9. Lecture globale synchronisée
10. Validation 4 / 8 / 16 mesures
11. Téléchargement / ré-upload
12. Reprise de session sans décalage temporel
